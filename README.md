# med-notes

An android app that shows an overview of medicines taken monthly or on a weekly basis

## Getting Started

### Installing

Install the latest version of Android studio

Setup your Android device

## Deployment

Clone or download the project.

Open the downloaded project in Android studio

Update the package dependencies

Connect your Android device and run the project

## Features

#### Monthly overview
Shows an overview of different moments grouped by date. Each moment is collapsible and shows the medicines to be taken. Checking the moment, sets all the medicines as taken.

#### Weekly overview
Shows an overview of the different medicines taken on a weekly basis. Each medicine is collapsible and shows details about the date and time when the medicine must be taken and also whether it was taken or not
